## Implementation

`packages/TallyAppleKit/Sources/TallyFeatures/Dashboard/DashboardView.swift`:
- `DashboardMomentumStreak` (internal `nonisolated enum`, same pattern as the existing
  `HeroCaption`): `.row(String)` or `.hidden`, from `StreakInsight` + `isParentModeHome`. Hides
  when `days == 0` (never "No current streak" on the Dashboard — the brief's own call, since the
  report does not ask for that copy to show) and whenever `isParentModeHome` (the report's streak
  is not described as parent-appropriate).
- `MomentumStreakRow` (private `View`): one line, `Label(streak.headline, systemImage: "flame")`
  (the exact icon+string pattern `InsightsScreen.momentumCard` already ships and the a11y audit
  already passed), `TallyTypography.footnote` / `TallyColor.textSecondary` (the Dashboard's
  existing caption-row scale), `.accessibilityIdentifier("dashboard.momentumStreak")`. Renders
  nothing when hidden (the `RemindersTip` pattern at the same file's `RemindersTip`/
  `RemindersViews.swift:27-37`).
- Wired into `DashboardView.body`'s `.loaded` case, after `WeekAheadSection`, before
  `DueSoonSection` — "under... the Week-ahead section" per the brief.

Zero new strings: `streak.headline` is `L10n.Insights.streakDays`/`.streakNone`, reused verbatim.
No new `TallyColor`/`TallyTypography`/`TallySpacing` values — every token already exists and is
already used elsewhere on this screen.
