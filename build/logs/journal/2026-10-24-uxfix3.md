## Implementation (one commit, `5b15695`)

Per-item detail is in the hand-off reply; notable judgment calls and things worth recording for
later:

- **UX2-09's shared `TallyNoticeLayout`** needed a `TallyStatusBarBand` TDS modifier of its own
  (ScreenChrome.swift): `AgeRestrictedView`/`SchoolRevokedNoticeView` have no `NavigationStack`/
  toolbar, so `tallyScreenChrome()`'s own D01 fix (an opaque `toolbarBackground`) has nothing to
  attach to. Reads the top safe-area inset with the same zero-footprint `GeometryReader` trick
  `TallyScreenWidthReader` already uses, then paints an opaque `bgCanvas` rectangle over exactly
  that band, ignoring the safe area. Applied unconditionally inside `TallyNoticeLayout`, including
  for `PurchaseConfirmationView` (which already has a toolbar): harmless, since both paint the
  same `bgCanvas`.
- **UX2-03's cap** could not be done by nesting a `.dynamicTypeSize` modifier below the
  `@ScaledMetric` property that computes the ring's diameter — `@ScaledMetric` reads the
  environment of the view that OWNS it, set by ancestors, not by modifiers applied to sibling/
  child content inside the same `body`. Extracted a `WeekDayMark` view with its own
  `@ScaledMetric`, instantiated with `.dynamicTypeSize(...DynamicTypeSize.accessibility1)` applied
  at the call site (an ancestor of `WeekDayMark`'s own body) — the same reasoning the existing
  busy-glyph cap already relies on, just one level removed since that one caps a plain `Image`
  with no `@ScaledMetric` of its own.
- **UX2-01** follows the report's literal prescription (`.annotation(position: .top...)` + hidden
  y-axis) rather than trying to reverse-engineer Swift Charts' pre-UX1-20 default behavior, which
  isn't independently verifiable from this host (no Xcode/simulator). Added a second
  `@ScaledMetric` (`nameLineHeight`, relative to `.caption`) for the extra annotation line instead
  of guessing a fixed point value.
- **UX2-02** uses the report's named alternative (`TallyReflowStack`/`TallyReflowValueColumn`, a
  new `.tallyStacking` `LabeledContentStyle`) rather than restructuring the screen into a
  `Form`/`List`, which would conflict with `TallyNoticeLayout`'s own `ScrollView`-based centring.
  This fixes the AX5 mid-word breaks (the S1 the brief's scope names) but not the std "no card"
  cosmetic note in the raw audit -- out of the brief's own narrower owner-approved wording for this
  item.
- **UX2-05/UX2-02 interaction**: `PurchaseConfirmationModel.amountText` also needed the word
  joiner (the report says so explicitly), which meant changing `SubscriptionOfferText.
  unbreakableSlash` from `private` to internal (module-visible) so a different file could call it.
  Found by re-reading `SubscriptionPlacementTests.swift` for every literal containing `/year` --
  one extra assertion (`model.amountText == "$9.99/year"`) needed the same update the research
  pass had already flagged for the other two.
- **UX2-06**: found and fixed a real bug in my own first draft before any CI run -- the Erase
  button's new `.foregroundStyle(ScreenPalette.color(...))` call referenced `colorScheme`/
  `contrast`, neither of which `SchoolRevokedNoticeView` declared as `@Environment` properties.
  Added both.
- **UX2-08/UX2-16 string-catalog mechanics**: confirmed via a background research pass that
  `check_string_catalogs.py` has no "stale key" allowance (the brief's own fallback clause), so
  followed the catalog's real precedent (`settings.language.footerV2`, found by that same pass):
  delete `reminders.footer` outright, add `reminders.footerV2`, update its own `L10n.swift`
  wrapper in place (not a new per-package file -- the precedent did the same), and hand-patch
  `L10N04SpanishFixture.swift`'s one listing (its generator script is not present in this
  worktree).
- **UX2-15**: the Canvas-links picker is a device preference shown in both the signed-in and
  sample-mode branches of `accountSection`; placed it next to School in the signed-in branch and
  near the top of the sample branch (which has no School row to sit beside).
- **Test gaps**: added six new a11y scenes (`AgeRestricted`, `SchoolRevoked` + its erase
  confirmation, `PurchaseConfirmation`, the subscribe interstitial, the Family empty state, the
