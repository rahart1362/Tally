# Checkpoints and Validation

## Checkpoint File Convention
Create one file per phase:
- `build/checkpoints/phase-P1.md`
- `build/checkpoints/phase-P2.md`
- etc.

## Minimum Content
- phase summary
- tasks complete / pending
- build status
- test status
- open risks
- next task

## Definition of Done
A task is done only when:
- code compiles
- tests pass or are explicitly documented as pending with reason
- acceptance criteria are met
- status files updated
- no privacy/security violation introduced
