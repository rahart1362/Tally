Tally for Canvas Administrators

A student at your school asked you to enable Tally. Here's what it is, and what enabling it involves.

What Tally is

Tally is an independent iOS app for students. It shows a student's own courses, grades, assignments, due dates and reminders, using that student's own Canvas sign-in.

  • There is no Tally server. A student's Canvas information goes from your Canvas directly to their iPhone, where it's stored encrypted and replaced on every refresh. Tally never receives it, stores it, or sees it.
  • There are no Tally student accounts. Tally has no account system of its own. A student signs in on your Canvas's own sign-in page, with your Canvas's own OAuth flow; Tally never sees a password.
  • Access is read-only, limited to the scopes below. A student's own sign-out revokes their token immediately.

What enabling Tally involves

Enabling Tally means creating one Canvas API developer key, which takes about five minutes:

  1. Admin → Developer Keys → + Developer Key → API Key.
  2. Fill in: Key Name "Tally"; Owner Email your own contact address; Redirect URI https://tally-app.dev/oauth/callback; Client type Public (PKCE, no client secret).

    ⚠︎ Whether your Canvas admin console exposes the "Public" client type option is unverified at the time of writing — if it doesn't, contact us (below) before proceeding.

  3. Enforce Scopes: ON. Select only the read-only scopes a student's own Tally needs:
Name, personal calendar feedurl:GET|/api/v1/users/:user_id/profile
Courses and scoresurl:GET|/api/v1/courses
Assignments and submissionsurl:GET|/api/v1/courses/:course_id/assignment_groups
Grading periodsurl:GET|/api/v1/courses/:course_id/grading_periods
To-do and due itemsurl:GET|/api/v1/planner/items
Course calendar eventsurl:GET|/api/v1/calendar_events
Announcementsurl:GET|/api/v1/announcements
Course coloursurl:GET|/api/v1/users/:id/colors

⚠︎ These scope strings come from Instructure's own API documentation; confirm them against the scope picker in your installed Canvas version before saving.

  1. Save, then switch the key's state to ON.
  2. Send us the key's Client ID (the numeric key ID — it isn't secret) using the contact link below. We add your school to Tally's institution directory, and students there can connect from then on.

To turn Tally off for your school at any time, set the key back to OFF; every Tally token issued to your school stops working immediately.

Optional: a parent or guardian can follow a student's due dates and grades through Canvas's own observer-account and pairing-code feature, with no extra setup beyond allowing observer self-registration. Ask us if you'd like the additional scopes this needs.
